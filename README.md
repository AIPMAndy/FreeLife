# FreeLife｜中国家庭消费省钱保姆级攻略

> 不为优惠而消费；只降低原本就需要发生的支出。更新基准：2026-11-27（中国标准时间）。

[在线查询](https://aipmandy.github.io/FreeLife/) · [维护规则](docs/MAINTAIN.md) · [AI 酋长 Andy](https://metaver.vip/) · [公司官网](https://www.a6no1.cn/) · 微信 `AIPMAndy`

FreeLife 是可离线运行的开放式消费权益目录，首版覆盖全国通用、北京/昌平和上海户籍相关政策。没有登录、没有广告返佣、没有外部脚本；浏览器可本地记录已办理项目与实际节省金额。数据来自公开资料，不包含任何家庭身份、住址、账户、证件或私人交易信息。

## 先做这五件事

1. 准备换电脑：京通领取电脑资格、核实具体SKU一级能效及商品国补标志、比较京东/天猫/Apple官翻、旧机估价，最后核查云闪付支付优惠。没有真实订单前不算已节省。
2. 有上海户籍三岁以下婴幼儿：搜索育儿补贴小程序或随申办，按孩子户籍申领；按年续领。不要向非官方人员透露验证码或转账。
3. 个税：符合条件的家庭核对婴幼儿照护、住房租金、赡养老人，扣除额不等于实际退税。
4. 日常：外卖/商超同篮同地址比价，优先检查已购订单价保，不凑单、不为小额券付会员费。
5. 北京出行：南邵等指定车站工作日7点前持一卡通半价；同一个支付媒介累计地铁月度优惠；亲子活动优先公共图书馆和免费博物馆。

## 计算口径

- 电脑：同款真实成交价 − 可核实平台优惠 − 合规政府补贴 − 可叠加支付优惠 − 旧机净回收价。旧机款单独列出，不计作省钱。若页面价格已含补贴，不重复扣减。实际资格须核验。
- 外卖/商超：同品牌、规格、数量、真实地址的商品实付 + 运费 + 包装费 + 实际会员摊销。赠品仅在原本需要且有确定价值时单列。
- 现金福利、消费折扣、税前扣除、回收变现分开记账。只登记已经到账、立减或退回的金额。税前扣除不要当成到账。
- 每条记录保留来源、核查日期、地区、截止条件、领取方法、限制。活动期限未结束也可能已无库存。没有官方来源的线索单列，不能标记可直接领取。

## 运行

直接双击 `index.html`（无需服务端）；或把项目文件上传到 GitHub 仓库，在 Settings → Pages 选择 main 分支 / root。网页自带数据，不依赖网络；点击来源时联网。数据增删后运行 `python3 scripts/build.py`，再运行 `python3 scripts/validate.py`。浏览器记录只在本机保存，可导出及导入 JSON。默认不显示已过期活动（已办理记录仍保留），可手动查看。

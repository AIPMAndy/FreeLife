# 维护与验收

1. 每周从京通、首都之窗、上海市政府、国家税务局、国家医保局、平台官方规则及银行App开始。发现新活动时，记录来源原文、核查日期、开始与结束时间、适用地址、账户资格、库存、金额和限制。
2. 使用 data/opportunities.json 作为唯一数据源。ID唯一、不得录入个人资料。status 必须区分政策有效、活动期间、媒体线索、常设渠道、已结束。deadline 若确切请写 YYYY-MM-DD；资金用完即止等写明条件。没有官方证据不得称为已领取。
3. 对大额采购先比较同SKU真实结算页，不自动抢券、登录、购买、注册或提交个人申请。不规避平台限制、不冒用账号、不虚构资格。
4. 只在实际省钱后在本地填写金额；税前扣除、可用券、回收金额、现金福利、消费折扣不要混加为同一类优惠。
5. 执行 python3 scripts/build.py 更新页面和 CSV，执行 python3 scripts/validate.py 验证。上线前手机端检查搜索、筛选、操作清单、导出和计算器；检查新增来源网址可访问。网页中的记录存储为 localStorage，不会上传服务器；切换浏览器需手动导出备份。

当前不配置自动定时任务。可按需安排人工复查；任何自动化都必须尊重网站使用条款和登录权限。
